## 🛠️ Tech Stack & Architecture

- **Core Framework:** Next.js 14.2.35 (App Router)
- **Library & Runtime:** React 18.3.1
- **Styling System:** Tailwind CSS 3.4.12 with custom HUD scanlines, chamfered corner clips, and theme tokens
- **Inertial Scrolling:** `@studio-freight/lenis` / `lenis` for smooth momentum glide with native accessibility
- **Motion Physics:** Framer Motion 11.5.4 (spring kinetics, hover spotlights, modal transitions)
- **Interactive Audio:** Synthetic Web Audio API oscillator synthesis (zero external audio dependencies)
- **Direct Dispatch API:** Next.js API route (`/api/contact`) with `nodemailer` Gmail SMTP integration
- **Typography:** `Inter Tight` (editorial display) & `JetBrains Mono` (technical metadata)

## 💻 Getting Started Locally

### Prerequisites
- Node.js 18+ (tested with Node 20 / 22)
- npm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/Adityasingh909/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev -p 3001
```

Open [http://localhost:3001](http://localhost:3001) in your browser.

### 4. Build for production
```bash
npm run build
npm start
```
